## 🚀 주요 기능

| 기능 | 설명 |
|------|------|
| 🔐 관리자 로그인 | Role 선택 (관리자/팀장/팀원), Google 로그인 UI |
| 📊 KPI 대시보드 | 8개 실시간 KPI 카드 + 미니 차트 |
| ✅ 업무 분장 시스템 | 팀원별 업무 카드, 진행률, 우선순위 |
| 💬 팀 채팅 | Slack 스타일 실시간 채팅 UI |
| 📅 일정 관리 | Google Calendar 스타일 월간 캘린더 |
| 📌 포스트잇 메모 | LocalStorage 저장, 색상별 메모 |
| 📈 생산성 분석 | 일/주/월/분기/연간 Chart.js 시각화 |
| 🤖 AI 브리핑 | 업무 요약, 충돌 감지, AI 채팅 |
| 📋 업무 결산 | 자동 생성 KPI 리포트 |
| 📧 Gmail 연동 | 메일 발송/수신 현황 |
| 🌙 다크/라이트 모드 | 테마 전환 지원 |
| ⚙️ 설정 모달 | 알림, 연동, 자동화 설정 |

---

## 🛠️ 기술 스택

- **HTML5** — 단일 파일 구조
- **CSS3** — Glassmorphism, 애니메이션, 반응형
- **Vanilla JavaScript** — 의존성 없는 순수 JS
- **Chart.js** — 다양한 차트 시각화
- **Font Awesome 6** — 아이콘
- **Google Fonts (Syne + DM Sans)** — 타이포그래피

## 📁 파일 구조

```
workos-pro/
├── index.html      ← 메인 (CSS + JS 내장)
├── README.md       ← 프로젝트 설명
├── railway.json    ← Railway 배포 설정
├── package.json    ← Node.js 서버 설정
└── github_link.txt ← 제출용 링크
```

---

## 🚀 로컬 실행

```bash
# 방법 1: 브라우저에서 직접 열기
open index.html

# 방법 2: Node.js 서버
npm install
npm start
# → http://localhost:3000
```
